# Global Guidelines

## Communication
- Always be concise. No more than a 3/4 sentences to answer my question. The exception to this is if I ask you to **explain** something, *e.g.*, "Explain to me how...". In this case, you can be more verbose.

## Programming
- Choose descriptive over concise variable names;
- For boolean variable use the prefix `is_` or `has_` to make it easy to infer that it is a true/false variable, *e.g.*, `is_enabled`
- Avoid exagerated abbreviations, *e.g.*, `nr` when you mean `nav_rec` (navigation record).
